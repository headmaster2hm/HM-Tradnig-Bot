FAQ

Frequently asked questions

Is it really 100% local?
Yes. The engine and dashboard run on your own machine at 127.0.0.1. There is no cloud account, no telemetry, and no external server involved in trading. The only optional internet use is sending Telegram notifications if you enable them.
Do I need MetaTrader 5?
For live trading, yes — you'll need a free MetaTrader 5 terminal and a broker account. For learning, you can still run the bot in dry-run with a simulated feed and explore the dashboard, backtest and history without touching a real account.
How does the one-time license work?
The first time you start the bot it shows an activation screen. You pay the one-time fee, receive a license key, paste it in, and the bot unlocks permanently. The key is validated locally and stored on your machine — it never expires, so reinstalling doesn't require a second payment.
Will it run on macOS or Linux?
Not yet. Windows 10/11 (64-bit) is the fully supported release. macOS and Linux builds are in development — use the waitlist above and we'll notify you when they ship. Your license will carry over.
Is the SmartScreen warning normal?
Yes. The installer isn't code-signed yet, so Windows may warn you on first run. Verify the SHA-256 checksum against the one on this page, then click More info → Run anyway.
How do I update the bot?
Just download the latest setup from this page and reinstall over the top — your settings, license and trade history are kept. There's no launcher or account needed.
Do I need a VPS or to leave my PC on 24/7?
The bot only trades while it's running. If you want round-the-clock automation you'll need to keep your PC (or a small Windows VPS you rent yourself) online — the software itself doesn't require or provide cloud hosting.
